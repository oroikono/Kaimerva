# Supplementary repository formats

Reviewed 7 October 2026, Europe/Zurich. These three primary-source comparisons supplement the two delegated eight-repository samples. Exact public API counts and inspected tree paths are in [the source snapshot](supplemental-repo-sources-2026-10-07.json). No sampled software was installed or executed. Recommendations below are inferences, not explanations of popularity.

## HyperFrames: a creative product agents can operate

[HyperFrames](https://github.com/heygen-com/hyperframes) has **58,180 stars and 5,180 forks** in the captured API snapshot. Its README leads with a concise output promise, useful destinations and an agent quickstart, then introduces workflows, domain skills, examples, contracts and packages. Its router separates creation tasks from technical capabilities. The actual tree separates `skills`, `examples`, `themes`, `registry` and runtime packages such as core, engine, producer, CLI and player. Root licensing is Apache-2.0.

**Transfer:** give Personal Worlds a concrete operating loop and a finished result to inspect; keep the skill, runtime, authored recipes and worked examples distinguishable. A future adaptation should produce a direction, working world, editable content and verified preview. Borrowing this organizational principle does not require a new renderer, custom CLI, cloud backend or the video's production pipeline. The README's local rendering claims were not tested here. [README](https://github.com/heygen-com/hyperframes/blob/main/README.md), [router](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes/SKILL.md), [packages](https://github.com/heygen-com/hyperframes/tree/main/packages).

## Three.js Skills: narrow technical modules

[CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) has **3,478 stars and 394 forks**. Its presentation moves through purpose, installation, a skill table, contextual loading examples, a common folder structure, verification claims and contribution guidance. The complete tree contains README and ten technical skill folders; these are renderer/API capabilities, not personal-world recipes.

**Transfer:** keep terrain, materials, camera and interaction references focused and load the chosen resource only. Keep a world family's story/art direction distinct from renderer reference material. Check every advertised installation path: this README points clone commands at another repository and mentions a directory that does not match the inspected source tree. It declares MIT, while the API detects no license and the inspected tree lacks a separate license file; no implementation reuse is proposed. Its API-audit assertions were not independently reproduced. [README](https://github.com/CloudAI-X/threejs-skills/blob/main/README.md), [actual skills](https://github.com/CloudAI-X/threejs-skills/tree/main/skills), [fundamentals](https://github.com/CloudAI-X/threejs-skills/blob/main/skills/threejs-fundamentals/SKILL.md).

## VoltAgent directory: distribution comes after demonstrated use

[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) has **35,300 stars and 3,796 forks**. It is a curated index, with a small root of README, contribution guide and license rather than an execution engine. Presentation centers on purpose, categorized links, harness paths, quality criteria and contributions. Its current contribution guide requires a working public skill, concise description and real community usage; brand-new skills are not accepted. [Contribution criteria](https://github.com/VoltAgent/awesome-agent-skills/blob/main/CONTRIBUTING.md).

**Transfer:** prepare a concise description and standard skill package now; seek directory inclusion after independent successful use. Listing is a distribution step, not proof of quality or a reason to add many unrelated capabilities. No submission was made.

## Rendered presentation observation

The [Impeccable homepage](https://impeccable.style/) was actually rendered in the in-app browser. Its hero places a large outcome statement beside a before/after sample, with an immediate install action, explanatory link, three command-preview controls and harness identities. This is stronger presentation evidence than merely reading a tagline. Its on-page star badge is older than the delegated API snapshot; the reports use the dated API count. No detector efficacy, engine run or other live interaction was tested, and no competitor screenshot was saved into the repository.

## Screening correction

Search indexes also surfaced a game-studio agent setup. The inspected [ml4k/claude-code-game-studios](https://github.com/ml4k/claude-code-game-studios) API returned **0 stars and 0 forks**, so it is excluded from the high-attention sample. Directory counts from another owner or an older entry are not assigned to this repository. Primary sources show modular skills, routers and creative frameworks already exist. Personal Worlds' case needs an original, useful portfolio workflow with observable adaptations, rather than a claim to have invented these mechanisms.
